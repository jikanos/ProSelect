# ProSelect

Автономный комплект АНО Де-Фриз для Windows. ProSelect проводит адаптивное тестирование, а отдельный анализатор собирает результаты группы.

## Запуск тестирования

Требуется Python 3.9+ с Tkinter. Сторонних зависимостей для запуска нет.

```powershell
py ProSelect.py
```

Введите ФИО и начните тестирование. Все темы включены автоматически. Интернет не требуется.

## Устройство проекта

- `ProSelect.py`: загрузка локального банка `questions.json`, интерфейс Tkinter и класс `ProSelectApp` с логикой сессии и адаптивных переходов.
- `results_dir()`: каталог результатов рядом со скриптом/EXE, резервный путь `~/ProSelect/results`.
- `atomic_json()`: запись JSON через временный файл, сброс на диск и атомарную замену.
- `analyzer/ProSelectAnalyzer.py` — приложение преподавателя для анализа результатов.
- `README_ProSelect.txt`: инструкция по запуску, тестированию и сборке.

Банк содержит 196 вопросов с уникальными кодами: компьютерная грамотность — 52, механика и инструменты — 38, физика и электроника — 57, технический английский — 49. Встроенный экспорт датирован 12.11.2026; актуальность относительно редакционного реестра отдельно не проверялась.

Тестирование проходит по всем темам в адаптивном режиме. На каждом уровне задаются три случайных вопроса. Два или три верных ответа позволяют перейти на следующий уровень. Неуспех завершает только текущую тему. Варианты ответов перемешиваются. На каждый вопрос отводится время из локального банка. По истечении времени вопрос закрывается, а пропуск учитывается отдельно.

У компьютерной грамотности имеются уровни 1–5, у остальных тем — 1–4. При отсутствии трёх вопросов на следующем уровне прототип завершает тему с причиной «Недостаточно вопросов».

## Результаты и публикация

Результаты кандидатов сохраняются после каждого ответа в `results/*.json` и при завершении теста. Эти файлы содержат пользовательские данные и не должны попадать в репозиторий. `.gitignore` исключает результаты, локальные секреты, временные файлы, окружения и сборки. Добавляйте исходники явно, проверяя состав коммита.

Банк и правильные ответы доступны в исходном коде. Результаты можно изменить вручную. Это прототип проверки знаний, не защищённая система аттестации.

## Анализ результатов группы

Запустите анализатор из корня репозитория.

```powershell
py analyzer/ProSelectAnalyzer.py
```

Выберите папку с результатами одной группы. Анализатор ищет JSON в ней и во всех подпапках, объединяет результаты в одну таблицу и учитывает копии одной попытки один раз.

- **Студенты** — рейтинг по числу правильных ответов и последний пройденный уровень по каждой теме. Двойной щелчок открывает детали попытки.
- **Уровни** — сколько попыток дошли до каждого уровня, завершили его и прошли.
- **Вопросы** — число учтённых показов, правильных ответов, ошибок и тайм-аутов.
- **Сохранить HTML** — отчёт с таблицами и деталями попыток для просмотра в браузере.

По щелчку на заголовок столбца можно изменить порядок сортировки. При наведении появляется пояснение к показателю.

[Инструкция по работе с анализатором и его сборке](analyzer/README.md).

## Сборка программы тестирования для Windows

```powershell
py -m pip install pyinstaller
py build.py
```

Результат: `dist/ProSelect.exe`. PyInstaller требуется только для сборки. Для чистой сборки на теге версия совпадает с тегом Git. Между тегами версия содержит расстояние до тега и хэш коммита. Суффикс `-dirty` означает локальные изменения. При запуске из исходников версия отображается как `dev`.

В JSON результата записываются `app_version` и `bank_sha256`. Хэш вычисляется по содержимому банка без учёта форматирования JSON и даты файла.
