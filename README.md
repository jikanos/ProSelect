# ProSelect

Автономный Windows-прототип проверки знаний кандидатов.

## Запуск

Требуется Python 3.9+ с Tkinter. Сторонних зависимостей для запуска нет.

```powershell
py ProSelect.py
```

Введите ФИО и начните тестирование. Все темы включены автоматически. Интернет не требуется.

## Текущая архитектура

- `ProSelect.py`: встроенный банк `QUESTIONS`, интерфейс Tkinter и класс `ProSelectApp` с логикой сессии и адаптивных переходов.
- `results_dir()`: каталог результатов рядом со скриптом/EXE, резервный путь `~/ProSelect/results`.
- `atomic_json()`: запись JSON через временный файл, сброс на диск и атомарную замену.
- `write_csv()`: экспорт завершённой сессии в CSV с разделителем `;` и UTF-8 BOM.
- `README_ProSelect.txt`: инструкция по запуску, тестированию и сборке.

Банк содержит 196 вопросов с уникальными кодами: компьютерная грамотность — 52, механика и инструменты — 38, физика и электроника — 57, технический английский — 49. Встроенный экспорт датирован 12.11.2026; актуальность относительно редакционного реестра отдельно не проверялась.

Тестирование проходит по всем темам в адаптивном режиме. На каждом уровне задаются три случайных вопроса. Два или три верных ответа позволяют перейти на следующий уровень. Неуспех завершает только текущую тему. Варианты ответов перемешиваются.

У компьютерной грамотности имеются уровни 1–5, у остальных тем — 1–4. При отсутствии трёх вопросов на следующем уровне прототип завершает тему с причиной «Недостаточно вопросов».

## Результаты и публикация

Результаты кандидатов сохраняются после каждого ответа в `results/*.json`; после завершения добавляется CSV. Эти файлы содержат пользовательские данные и не должны попадать в репозиторий. `.gitignore` исключает результаты, локальные секреты, временные файлы, окружения и сборки. Добавляйте исходники явно, проверяя состав коммита.

Банк и правильные ответы доступны в исходном коде. Результаты можно изменить вручную. Это прототип проверки знаний, не защищённая система аттестации.

## Сборка Windows

```powershell
py -m pip install pyinstaller
py -m PyInstaller --noconfirm --clean --onefile --windowed --add-data "de-friz_logo.png;." --name ProSelect ProSelect.py
```

Результат: `dist/ProSelect.exe`. PyInstaller требуется только для сборки. Сборка EXE в рамках первоначальной публикации не проверена.

## Направления развития

С учётом контекста «Анкетирование» от 14.11.2026:

1. Отделить движок тестирования от интерфейса, банка и хранения результатов; закрепить сценарии 2/3, остановки одной темы и окончания доступных уровней тестами.
2. Версионировать JSON-формат результатов, сохранять полный показанный порядок вариантов, состояние уровня и очереди; добавить восстановление прерванных сессий и обработку ошибок записи.
3. Перенести утверждённый банк в SQLite без изменения вопросов и кодов. Импортёр должен поддерживать обе схемы редакционного реестра, проверять уникальность кодов, варианты и уровни. Новые вопросы требуют явного утверждения.
4. Добавить итоговый разбор ответов и пробелов, согласовать поведение при нехватке вопросов и завершении последнего доступного уровня.
5. Добавить обновления опубликованного банка: версия, контрольная сумма, проверка схемы, атомарная установка и откат. Сбой сети не должен мешать офлайн-тестированию.
6. Проверить интерфейс Windows и сборку EXE; затем отдельно спроектировать защищённую онлайн-отправку результатов без секретов в публичном репозитории.

SQLite, обновления, восстановление сессий и онлайн-отправка в текущем прототипе отсутствуют. Смена GUI-фреймворка не утверждена.
