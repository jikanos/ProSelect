FPV-TEST — ПРОБНАЯ ОФЛАЙН-ПРОГРАММА
================================

Состав
------
FPV_Test.py — вся программа и 196 вопросов, встроенных непосредственно в код.
Дополнительные базы данных или подключения к сети не требуются.

Источник вопросов
----------------
Google Sheets «Профотбор», выгрузка 12.11.2026:
- Компьютерная грамотность: 52 вопроса
- Механика и инструменты: 38 вопросов
- Физика и электроника: 57 вопросов
- Технический английский: 49 вопросов
Итого: 196 вопросов.

Запуск
------
1. Установить Python 3.9 или новее с поддержкой Tkinter.
2. В Windows дважды щёлкнуть FPV_Test.py или выполнить:
   py FPV_Test.py
3. Ввести ФИО/идентификатор, выбрать тему и режим, начать тестирование.

Режимы
------
- Адаптивный: 3 вопроса на уровень, переход если верны >=2 из 3;
  при неуспехе прекращается только текущая тема.
- Все вопросы: все вопросы выбранных тем в случайном порядке.
Варианты ответов перемешиваются в обоих режимах.

Результаты
----------
Создаётся папка results рядом с файлом программы.
Если писать туда нельзя, используется ~/FPV-Test/results.
После каждого ответа обновляется файл <дата>_<id>.json.
После завершения теста также создаётся CSV-файл для Excel.
Если закрыть программу посередине, уже введённые ответы сохранятся
в JSON; продолжения незавершённого теста в этой версии нет.

Сборка одного EXE в Windows
--------------------------
При наличии Python в Windows выполните:
  py -m pip install pyinstaller
  py -m PyInstaller --noconfirm --clean --onefile --windowed --name FPV-Test FPV_Test.py
Готовый файл: dist/FPV-Test.exe
Папка results будет создаваться при запуске рядом с EXE
(если есть права на запись).

Ограничения прототипа
--------------------
- Синхронизации с GitHub/Google Sheets нет.
- Вопросы и правильные ответы видны в исходном коде Python.
- Файлы результатов можно изменять вручную; это не защищённая аттестация.
- GUI проверен на уровне компиляции и логики сохранения, но не запускался
  в графической среде Windows.
