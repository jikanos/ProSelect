# Анализ результатов ProSelect

Запустите `dist/ProSelectAnalyzer.exe` или выполните из корня репозитория:

```powershell
py analyzer/ProSelectAnalyzer.py
```

Для запуска из исходников нужен Python 3.9+ с Tkinter. Программа работает локально.

1. Нажмите **Выбрать папку** и укажите папку с результатами одной группы. JSON-файлы из этой папки и всех её подпапок попадут в один отчёт.
2. На вкладке **Студенты** откройте детали кнопкой или двойным щелчком. По каждой теме указан последний пройденный уровень. Ноль означает, что первый уровень не пройден.
3. На вкладках **Уровни** и **Вопросы** посмотрите групповую статистику. На вкладке вопросов выберите строку, чтобы прочитать длинный текст целиком.
4. Нажмите **Сохранить HTML**. Отчёт открывается в браузере и содержит все три таблицы и раскрываемые детали попыток.

Один балл соответствует одному правильному ответу. Рейтинг отсортирован по убыванию баллов. При равном балле место одинаковое, строки упорядочены по ФИО. Каждая отдельная попытка занимает строку, включая незавершённые попытки с их текущими баллами. Копии одного результата учитываются один раз по идентификатору попытки.

В статистике по уровням «Дошли» означает, что есть хотя бы один записанный ответ или тайм-аут. Процент прохождения считается среди попыток со всеми тремя записями уровня. В статистике вопросов процент верных считается от всех записей вопроса, включая тайм-ауты. Программа показывает замечания по пропущенным файлам.

## Сборка Windows

Из корня репозитория:

```powershell
py -m pip install pyinstaller
py build.py analyzer
```

Готовый файл — `dist/ProSelectAnalyzer.exe`.
